Signl is a fan-to-artist platform: artist pages, a merch path, and a way for an
artist to know who their audience actually is. It is here for one reason, and it
is not the music. The machine underneath it is the same one running the clinic
funnel, pointed at a different industry.

Front end is Next.js with Supabase. The interesting part is behind it.

## The same spine

GoHighLevel is not a bolt-on here, it is the spine. Artist pages are built in the
GHL builder. Merch runs through a GHL modal over Shopify, so the commerce is
Shopify's problem and the customer is GHL's. Thank-yous, customer capture,
abandoned carts and segmentation all live there rather than being reimplemented
in the app.

The Fan Connect module is a lead-capture pipeline in different clothes. A fan
signing up to hear from an artist and a lead asking about a clinic are the same
event: capture, validate, tag, segment, then message on a schedule that respects
where the person is. Six third-party APIs sit behind it.

## The part that generalises

Consent is where this earns its place next to the timezone work.

Signl has to satisfy GDPR and California privacy rules from one implementation.
The naive build forks — a European path, a Californian one, a default — and every
later feature has to be written three times, then gets written correctly twice.

I used the same shape as the [scheduling engine](/systems/scheduling-timezone).
Resolve the visitor's jurisdiction once, at the edge, into a small set of facts
about what is permitted. One code path reads those facts. A hard question about
where somebody is, answered once, so nothing downstream has to know it was hard.
